# Components

현재 Web 앱은 공유 UI primitive 디렉터리가 아직 없습니다. 버튼, 입력, 패널, 상태 배지는 `apps/web/src/main.tsx`의 JSX와 `apps/web/src/styles.css`의 class selector로 직접 구현되어 있습니다.

## Inline UI Primitives

- Source: `apps/web/src/main.tsx`
- Styles: `apps/web/src/styles.css`
- Components: icon button, primary button, text input, textarea, status badge, panel, task row, event row
- Library icons: `lucide-react`

```tsx
// Shared primitives are currently inline in apps/web/src/main.tsx.
// The full source file should be used as context for design work:
// apps/web/src/main.tsx
```

```css
/* Primitive styles are currently defined in apps/web/src/styles.css.
   The full CSS file should be used as context for design work:
   apps/web/src/styles.css */
```
